🎯 Output: Motor Response & Fitts' Law (費茨定律) Slides 26 - 42

📐 核心公式家族 (Slide 31, 40, 41)

  • 運動時間公式：T = a + b · ID = a + b · log₂(2D / W)
  • Shannon 修正難度：ID = log₂(A/W + 1) 或 ID = log₂(A/W + 0.5) (當 $ID < 3$ bits)。
  • 表現指數 (Index of Performance)：IP = 1 / b (bits/sec)。$ID$ 取決於任務 (Task)，而 $a, b$ 決定設備 (Device) 有多快！

❓ 為什麼 Fitts' Law 有對數 (Logarithm)？ (Slides 32 - 34)

  • 1. Speed-accuracy tradeoff：難度增加時耗時呈邊際遞減 (Diminishing returns)。
  • 2. Information theory：香農帶噪信道容量以比特 ($\log_2$) 計算。
  • 3. Empirical fit：完美擬合人類實驗數據。
  • 4. Doubling/halving effect：距離 $D$ 翻倍或寬度 $W$ 減半，$\log_2$ 項僅固定增加 1 bit。

⏱️ 反應時間與心理計時學 (Mental Chronometry) Slides 43 - 49

  • Reaction Time (取決於刺激類型 Stimulus Type, Slide 44)：Visual (~200 ms) < Pain (~700 ms) < Auditory (~1500 ms)。
  • Response / Motor Time (取決於受試者身體特徵)：如年齡 (Age)、體能 (Fitness level)。
  • 射擊遊戲時間準備公式 (Slide 49)：EPP = SOA + D_S2 - D_S1（有效準備期 EPP 加速對敵人 $S_2$ 的中樞處理 Central S2）。
